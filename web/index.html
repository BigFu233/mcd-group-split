第一次用，先连上你的麦当劳账号

Token 只保存在你自己手机的浏览器里，用来向麦当劳官方 MCP 取菜单和券包，不会上传到任何第三方，也不会写进服务器文件。

1
打开 open.mcd.cn/mcp， 手机号登录，点右上角「控制台」。
2
点 激活 → 同意服务协议 → 复制 Token（一长串字母数字）。
3
回来粘贴 → 验证 Token → 填 城市 + 门店关键词 → 拉取菜单。
以后打开就直接用，不用再填。
